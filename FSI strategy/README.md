# EAIND — FSI Strategy

Working folder for the Engineering, AI and Data (EAIND) financial services
go-to-market and activation strategy.

## Contents

- `EAIND-FSI-Strategy-Development-Plan.pptx` — the plan for *developing* the
  strategy. Framework only: it sets out the questions, the principles, the
  five-step approach, the workstreams and the three-week cycle. It deliberately
  contains no answers — no markets, accounts, offerings, targets or owners.
- `make_deck.js` — generator for the deck (`node make_deck.js`, needs
  `npm install pptxgenjs`). Edit the script if you want the deck reproducible,
  or edit the .pptx directly if you prefer.

## Deck contents

1. Title
2. What this document is — method, not conclusion
3. Five questions to answer — where to play, what we offer, how we win, how much, who covers what
4. Principles we hold going in
5. How we will get there — five steps: Mobilise, Baseline, Define, Quantify, Commit
6. Five workstreams, five artefacts
7. The three-week journey — Frame, Define, Commit, with a gate each week
8. How we run it — cadence, inputs needed, decisions requested
