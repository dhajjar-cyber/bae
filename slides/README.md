# Slides

`bae-overview.pptx` — starter deck on the library (8 slides, 16:9).

Regenerate after editing `make_deck.js`:

```bash
npm install pptxgenjs      # once
node make_deck.js
```

Edit either file — the `.pptx` directly in PowerPoint, or the script if you
want the deck reproducible. If you edit both, the script wins on the next run.

Open items are listed on the last slide; speaker notes flag the placeholders
(no performance numbers are quoted anywhere yet — they haven't been measured).
